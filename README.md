# Shaheer Ali — Portfolio (Next.js)

Personal portfolio site for **Shaheer Ali**, Software Engineer specializing in
Node.js, NestJS, TypeScript, and scalable backend systems.

**Live:** https://shaheer-ali.vercel.app

## Tech Stack

- **Next.js 15** (App Router, Server Components)
- **TypeScript**
- **Tailwind CSS 4** (CSS-based theme config)
- **Framer Motion** — scroll/entrance animations
- **lucide-react** — icons
- **next-themes** — dark/light mode toggle
- **next/font** — self-hosted Inter + JetBrains Mono (zero layout shift)
- **class-variance-authority + tailwind-merge** — utility class management
- **resend** — contact form email delivery (optional; requires env var)

## Getting Started

```bash
# Install dependencies
npm install

# Run the dev server
npm run dev

# Build for production
npm run build

# Start the production build locally
npm start

# Lint
npm run lint
```

Open http://localhost:3000 to view it.

## Editing Content

All portfolio content lives in `src/data/`:

| File | Controls |
|------|----------|
| `site-config.ts` | Name, title, headline, contact info, social links, resume URL |
| `about.ts` | About background, technical focus, strengths, engineering highlights |
| `skills.ts` | Skills grid organized by category |
| `experience.ts` | Work history timeline |
| `projects.ts` | Project cards + case-study data + slugs (feeds `/projects/[slug]`) |
| `education.ts` | Education section |
| `articles.ts` | Technical writing model (no articles published yet) |

To update your resume PDF, replace `public/resume.pdf` (keep the filename the same so download links keep working).

## Features

- **Dark mode by default** with light/dark toggle (persists preference)
- **Fully responsive** mobile-first layout with hamburger menu
- **Active section highlighting** in navbar via IntersectionObserver
- **Scroll animations** via Framer Motion (fade-in on viewport entry), with `prefers-reduced-motion` support
- **Skip-to-content link** for keyboard accessibility
- **About section** positioning Shaheer as a backend engineer
- **Engineering Focus section** highlighting capability areas (APIs, payments, real-time, databases, RBAC, cloud)
- **Featured project case studies** with dedicated `/projects/[slug]` pages (problem, solution, architecture, responsibilities, challenges, key features)
- **Contact form** with client + server-side validation, accessible labels, and rate limiting (Resend API)
- **SEO optimized** — Metadata API (OG tags, Twitter cards, sitemap, robots.txt) + JSON-LD `Person` & `WebSite` schema + per-project metadata
- **Zero layout shift** with self-hosted Google Fonts via `next/font`
- **Data-driven** — all content lives in typed `src/data/*.ts` files, no hardcoded JSX arrays
- **Accessible** — semantic HTML, ARIA labels, focus-visible rings, keyboard navigation, good color contrast
- **Gradient project banners** — color-coded visual headers for each project card

## Deployment

Deployed on **Vercel**. Pushing to `main` (or your deployment branch) triggers an automatic build and deploy.

Manual deploy:
```bash
vercel --prod
```
